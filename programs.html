Computer Science & Engineering Program

Program Overview

The B.Tech Computer Science program is designed to equip students with fundamental and advanced knowledge in computer systems, programming, algorithms, and software development.

Key Specializations

  • Artificial Intelligence and Machine Learning
  • Cloud Computing and DevOps
  • Cybersecurity and Information Security
  • Web Development and Mobile Applications
  • Data Science and Big Data Analytics

Course Structure

  • Core subjects: Data Structures, Algorithms, Database Management
  • Programming languages: C, C++, Java, Python, JavaScript
  • Elective courses: AI, ML, Cloud, Security
  • Practical lab work and projects
  • Industry internships in final year

Data Science & AI Program

Program Overview

This interdisciplinary program combines computer science, statistics, and domain expertise to develop professionals skilled in extracting insights from data and building intelligent systems.

Learning Outcomes

  • Master statistical analysis and data visualization techniques
  • Develop machine learning models for real-world problems
  • Implement deep learning and neural networks
  • Work with big data platforms and tools
  • Deploy AI models in production environments

Tools & Technologies Covered

  • Python, R, SQL
  • TensorFlow, PyTorch, Scikit-learn
  • Apache Spark, Hadoop
  • Tableau, Power BI for visualization
  • AWS, Azure cloud platforms
